# Deadline Tracker

A simple, circular countdown timer designed to help users track deadlines, monitor progress, and see how much time remains before a target is reached.

## Features

- Circular progress indicator for the countdown.
- Toggle between elapsed time and time remaining.
- Separate overtime indicator when the target duration is exceeded.
- Start and stop controls.
- Summary of the final timing result.
- Progressive Web App (PWA) support.
- Offline functionality through a service worker.

## Technologies

- HTML
- CSS
- JavaScript
- Web App Manifest
- Service Worker

## Running Locally

1. Clone or download this repository.
2. Open the project folder in a code editor.
3. Serve `index.html` using a local development server, such as the Live Server extension in Visual Studio Code.
4. Open the local address provided by the server in your browser.

## Project Status

This project is under development. Features and the user experience may change as development continues.
